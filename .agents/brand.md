This file records the brand evidence that exists in this repository. Treat
unspecified choices as open design work, not established brand rules.

## Name

Use `instaclaw` in lowercase. The README uses this spelling as the project
name. Do not introduce `InstaClaw`, `Insta Claw`, or another wordmark.

## Product description

Use the repository's current description: an Instagram saved scraper that
turns saved items into structured exports for agents.

Do not name export formats, interfaces, delivery methods, or supported
workflows until the repository implements and documents them.

## Voice

Write short, direct descriptions of what the tool does. Prefer concrete verbs
such as `scrape`, `export`, and `structure`. Avoid claims about speed, scale,
privacy, platform approval, or reliability without evidence.

present a proposed visual choice as established brand guidance.
